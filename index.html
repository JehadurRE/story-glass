Relay settings

Browsers block direct calls to Instagram/Facebook (CORS). Point this at StoryGlass relay — local node scripts/local-relay.mjs or a deployed Cloudflare Worker.     If auto-resolve fails

    • Story may be private, expired (~24h), or removed.
    • Username-only links need Instagram’s private story API — use a single-story link instead.
    • Use Manual paste with page source or JSON from a new tab.

    What “client-side” and “anonymous” mean here

    All UI, URL parsing, players, and downloads run in your browser. StoryGlass has no visitor accounts and does not host media. Because Meta blocks cross-origin reads, the page may call a CORS relay you choose.

    Not anonymous toward Instagram. If you enable IG_SESSIONID, your Worker uses a logged-in account to read stories. Instagram can (and often does) show that account in the creator’s story viewer list. Loading the CDN file after you already have the URL does not by itself register a new view — but getting the URL via that session is what risks the view. Facebook public video HTML extract does not need a login and is a different path.

    Private accounts stay private. This tool does not bypass login walls or audience restrictions.

    FAQ

    Is this an anonymous Instagram story viewer?

    No. “No account” means you do not sign up for StoryGlass. If Instagram stories are resolved via IG_SESSIONID, that logged-in server account may show up in the creator’s viewer list. We do not offer stealth viewing.

    Do I need an Instagram or Facebook account to use this?

    No account on StoryGlass. Facebook public videos work without any Meta login. Instagram stories require your Worker’s optional session.

    Why not “pure” static fetch to Instagram?

    CORS. The browser will not let this origin read Instagram/Facebook responses. A relay or manual paste is required for real data.

    Does it work on phone?

    Yes — modern mobile browsers are first-class. Copy link from the app, paste here.

    Can I download in full HD?

    You get whatever resolution the public CDN returns. We do not upscale or invent quality.
